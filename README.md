# Beadwork 3D Archive 2025

## Overview
This project is a high-fidelity 3D archival platform dedicated to preserving and licensing traditional Kenyan beadwork and textile patterns. Using WebGL and Three.js, it provides an immersive way to interact with intricate bead patterns, ensuring cultural heritage is documented in a digital-first format.

## Features
- **Procedural Rendering**: Generates beadwork patterns dynamically based on traditional schemas.
- **Archive Metadata**: Support for licensing terms and cultural provenance.
- **High Fidelity**: Detailed geometry simulating individual glass and clay beads.

## Tech Stack
- **Engine**: Three.js
- **Language**: JavaScript (ES6+)
- **Dev Tools**: Vite (recommended)

## Setup
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. View at `http://localhost:5173`

## Licensing
All patterns displayed are subject to Communal Intellectual Property rights of the respective Kenyan ethnic groups. Commercial licensing modules are included in the `/licensing` directory.
